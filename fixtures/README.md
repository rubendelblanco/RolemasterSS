# Fixtures - RMSS Reference Data

This folder contains JSON data generated from Rolemaster manuals, meant to be imported into Foundry VTT compendiums.

## Folder overview

- **spell_lists/en/essence/** – Spell lists in English (Essence)
- **spell_lists/es/essence/** – Spell lists in Spanish (Essence)
- **spell_lists/en/channeling/** – Spell lists in English (Channeling)
- **spell_lists/es/channeling/** – Spell lists in Spanish (Channeling)
- **spell_lists/en/arcane/** – Spell lists in English (Arcane, Magehunter)
- **spell_lists/es/arcane/** – Spell lists in Spanish (Arcane, Magehunter)
- **spell_lists/en/mentalism/** – Spell lists in English (Mentalism)
- **spell_lists/es/mentalism/** – Spell lists in Spanish (Mentalism)

Every list below is available in both languages, at the same relative path under `en/` or `es/`.

## How to import

### Option 1: Simple macro (recommended)

Use **Option A** of the macro below: it creates the item in the world, then you drag it into whichever compendium you want from the Items tab.

### Option 2: Import macro

Create a macro in Foundry and run it to import a fixture.

**Option A – Create in the world (Items sidebar):**

```javascript
// Creates the item in the world's Items directory. You can then drag it into a compendium.
// Use "es" or "en" depending on the language you want:
const fixture = await fetch("/systems/rmss/fixtures/spell_lists/es/essence/detecting_ways.json").then(r => r.json());
const existing = game.items.find(i => i.type === "spell_list" && i.name === fixture.name);
if (existing) {
  ui.notifications.warn(`"${fixture.name}" already exists in Items. Not duplicated.`);
} else {
  const item = await Item.create(fixture);
  ui.notifications.info(`"${item.name}" created in Items. Drag it into a compendium if you want.`);
}
```

**Option B – Import into an existing compendium:**

```javascript
// 1. Create an Items compendium (Compendium Packs → Create Compendium).
// 2. Replace PACK_ID with the real ID (e.g. "world.spell-lists").
const PACK_ID = "world.spell-lists"; // ← Change this to your compendium
const fixture = await fetch("/systems/rmss/fixtures/spell_lists/es/essence/detecting_ways.json").then(r => r.json());
const pack = game.packs.get(PACK_ID);
if (!pack) {
  ui.notifications.error(`Compendium "${PACK_ID}" not found. Create one first.`);
} else {
  const already = (await pack.getIndex()).some(e => e.name === fixture.name);
  if (already) {
    ui.notifications.warn(`"${fixture.name}" already exists in ${pack.metadata.label}. Not duplicated.`);
  } else {
    await pack.importDocument(fixture);
    ui.notifications.info(`"${fixture.name}" imported into ${pack.metadata.label}.`);
  }
}
```

```javascript

// Change FOLDER to: essence, channeling, arcane, mentalism, or essence/training-packages.
```

### Option 3: Manual import

Create a Spell List item in a compendium, open the JSON in an editor, and copy/paste the data into the item (if the system allows it).

## Format

Fixture files follow Foundry's Item structure for `spell_list`:
- `name`, `type`, `img` at the root level (default image: `systems/rmss/assets/default/spell.svg`)
- `system.type` – "open" | "closed" | "base"
- `system.realm` – "essence" | "channeling" | "mentalism" | "arcane"
- `system.profession` – present on `"base"` lists; identifies the owning profession (e.g. "Paladin", "cleric")
- `system.spells` – array of embedded spells with `{ name, img, system }` (each spell uses `spell.svg` by default)
