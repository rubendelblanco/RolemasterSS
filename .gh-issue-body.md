## Problema
Muchas criaturas de Rolemaster tienen reglas de combate que no son ataques normales:
- **Drenajes** (ej: -3 Constitución por ronda si falla RR)
- **Requisitos de armas** (ej: solo armas mágicas pueden dañar)
- **Efectos especiales** al morir (ej: cadáver se disipa)
- **Condiciones de contacto** (ej: "por ronda de contacto")

Actualmente solo existe el campo **Description**, que mezcla todo. Sería útil tener un campo dedicado para estas reglas de combate.

## Propuesta
- Añadir campo `system.combat_notes` o `system.special_abilities` en creatures/NPCs
- Editor WYSIWYG (como Description) para texto enriquecido
- Sección visible en la pestaña de ataques, debajo de la tabla de ataques y antes o después de Description

## Alternativas de nombre
- "Combat" (como en el manual)
- "Special Abilities"
- "Combat Notes"
- "Special Combat Rules"

## Alcance futuro (opcional)
- Automatización de drenajes (RR fallido → aplicar efecto)
- Validación de requisitos de armas antes de daño
